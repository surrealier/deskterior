# Deskterior

**A pixel-art desk that lives on your macOS desktop.** Your Desktop files sit on the in-scene monitor;
hide them in drawers, the pen cup, the phone stand, the wastebasket or under a cloth desk mat — or just
press the monitor's power button. Hiding only changes the layout; your files never move unless you ask.

> 🚧 Work in progress — see [`docs/DESIGN.md`](docs/DESIGN.md) for the full design.

[한국어 README](README.ko.md) (coming soon)

## Build from source
Requires macOS 14+ and Swift 6.2 (Xcode or the Command Line Tools).

```sh
make build   # swift build
make test    # swift-testing suites
make lint    # file-safety lint
```

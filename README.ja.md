# Deskterior（デスクテリア）

本物の机を片づけるように、Macのデスクトップをピクセルアートで片づけましょう。

**Macのデスクトップに住む、ピクセルアートのデスク**です。DeskteriorはMacのデスクトップ整理アプリです。デスクトップをFinderのアイコンごと明かりのともる小さな部屋で覆い、デスクトップにあるファイルをデスクのモニターにアイコンとして表示します。片づけ方は本物の机と同じです。モニター台の引き出しやファイルキャビネットにしまう、スマートフォンスタンドやペン立てに置く、くずかごに放り込む、ブラシで布のデスクマットの下に掃き込む。モニターの電源ボタンを押すだけでもかまいません。隠しても変わるのはレイアウトだけです。ファイルは元の場所にあり、あなたがはっきり頼んだときにしか変更されません。

アプリの画面（メニュー、ボタン、メッセージ、設定）は英語と韓国語で表示され、Macの言語設定に合わせてどちらかが選ばれます（それ以外の言語では英語）。そのため、このREADMEではアプリの項目名を英語のまま記し、必要に応じて括弧内に訳を添えています。

## 機能一覧

各部分の使い方は、下の[隠し場所の使い方](#隠し場所の使い方)と[操作方法](#操作方法)の表にあります。

### モニター

- **リアルタイムのデスクトップ**：デスクトップフォルダ（または自分で選んだ別のフォルダ）の変化をそのまま映します。新しいファイルは印刷されるように現れ、名前を変えたファイルは場所を保ち、なくなったファイルはポンと消えます。ファイルは名前ではなくファイルそのもので見分けるので、名前の変更や置き換え保存のあとも場所はそのままです。7日以内に戻ってきたファイルは、元の場所に戻ります。
- **本物のアイコンを、ピクセルで**：各ファイルには自分のFinderアイコンが、画像・動画・PDFにはクイックルックのサムネイルが、デスクの色でピクセル化されて表示されます。本物のアイコンの準備ができるまでは、種類ごとの手描きアイコンが表示されます。ダウンロードされていないiCloudのファイルはそのままです。種類のアイコンで表示し、ダウンロードはしません。
- **名前は韓国語も**：名前はピクセルフォントGalmuri9で描かれ、韓国語にも対応しています。分解された形で保存された名前（Macの韓国語のファイル名によくあります）は先に合成（NFC）するので、ハングルが崩れずに表示されます。絵文字もピクセルで描きます。
- **ページと入力**：1ページに45個（9 × 5）で、ページごとに1つの入力があり、デスクトップが埋まるにつれてHDMI 1、2…と増えます。INPUT、画面の上での2本指スクロール、Inputメニュー（各ページのファイル数を表示）でページを切り替えます。運んでいるファイルをINPUTの上にしばらく置くと、次のページに切り替わります。
- **AV**：常に空の入力です。すべてを隠すもう1つの方法で、跳ね回るNO SIGNALのロゴは10秒後に止まります。
- **電源**：⏻を押すと、昔のブラウン管のように画面がしぼんで消え、すべてのページが隠れます。電源が切れている間にファイルが届くと、琥珀色のLEDと「+N」バッジが点灯します。
- **Clean Up By**：モニターの右クリックメニューから、Name（名前）、Kind（種類）、Date Added（追加日）のいずれかで整頓します。
- **選択とキー**：クリック、⌘-クリック、空いた画面でのドラッグによる囲み、⌘Aで選択します。矢印キーで選択を移動し、SpaceでQuick Look、⌘Oで開く、⌘Cでコピーです。ファイルを別のマスへドラッグしたり（ふさがっているマスなら入れ替わります）、複数をまとめて運んだりできます。
- **初回起動**：ウェルカムウインドウがデスクを紹介し、デスクトップを読み込む前に、モニターが⏻を押すよう促します。アクセスが拒否された場合は、Open SettingsとChoose Folder…を表示します（[初回起動](#初回起動)を参照）。

### 隠し場所

- **モニター台の引き出し**（2つ）：1つに8個まで入ります。それを超えると少し開いたままになり（中身は隠れたまま）、14個で詰まってBONKとはね返します。閉じた引き出しにファイルをドロップすると、ぱくっと飲み込みます。取っ手をクリックするかドラッグして開け、上でスクロールすると中をのぞけます。運んでいるファイルを上にかざすと、ぱっと開きます。勢いよく閉めるとバタンと鳴ります（バタンと閉めると、デスクを叩いたときのように揺れます）。
- **小物棚**：12個のファイルがぼんやりしたシルエットで並び、ポインタを重ねると名前が出ます。半分しか隠しません。
- **ファイルキャビネット**（引き出し3段：8個、12個、20個。それぞれ6個多く入れると詰まります）：一度に開く引き出しは1つだけです。いちばん下の引き出しは、種類ごとに色分けされたフォルダタブで書類を整理します。椅子が前にあると、引き出しは少ししか開かずに椅子にぶつかり、椅子が脇へ転がっていくので、次に引けば開きます。
- **椅子**：ドラッグすると転がり、勢いよく放すと滑りながらくるくる回ります。
- **スマートフォン**：最大6個のファイルが小さなアプリアイコンになります。クリックすると伏せられます（中身は隠れ、ドロップするとBONK）。表向きのときは、夜に光ります。
- **ペン立て**：ペンは6本まで、キャップは種類ごとの色です（7本目はBONK）。最後に入れたペンを引き抜けます。ペン立てをデスクの上でドラッグすると、山を押しのけます。ペンが3本以上入った状態ではじくと（またはTip Overを選ぶと）倒れて、ペンが山になってこぼれます。クリックすると起き上がります。
- **くずかご**：丸めた紙が24個まで入り、11個目からはふちより上に山盛りになります。ファイルをドロップしたり放り込んだりできます（きれいに入ればSWISH!、ふちに当たると跳ね返り、外れると床に落ちます）。いちばん上の紙を取り出したり、ふちを横にドラッグして倒したりできます（紙は広がって床に散らばります）。削除は決してしません。Empty Wastebasket…は、中身の一覧を表示して確認したあとで、それらをmacOSのゴミ箱に移します。
- **メニュー**：引き出しにはOpen Drawer／Close Drawer、スマートフォンにはTurn Face Up／Turn Face Downがあり、引き出し、小物棚、スマートフォンのどれにもList Contents（名前を選ぶとモニターに送ります）、Move Contents to、Take All Outがあります。ペン立てとくずかごにはTip OverとStand Upがあります。どのファイルも、Move to ▸ ですぐに隠し場所へ送れます。
- **勝手に出てくることはありません**：叩いても、バタンと閉めても、入れすぎても、入れ物が空になることはありません。入れすぎるとBONKとはね返すだけです。

### しまう

- **Put Away**（しまう）：使わない物はしまっておけます。モニター台の引き出し（モニター台はただのモニター置きとして残ります）、ファイルキャビネット、スマートフォンスタンド、鉢植え、デスクパーティションやその付属品、壁の棚・有孔ボード・ストリングライト・床の鉢植え・壁飾りが対象です。右クリック ▸ Put Away（たとえばPut Away Plant）、メニューバーのメニューのPut Away ▸、またはすべてを一覧できるArrange Desk…（デスクを整理）を使います。
- **中には残りません**：ファイルが入っている場所はメニューでそう示し（「Take Out 3 & Put Away Cabinet」）、ファイルを先にモニターへ出してからしまいます。取り消しは1回で両方戻ります。
- **Bring Back**（戻す）：Bring Back ▸で一つずつ、Bring Everything Backでまとめて戻せます。戻る場所にあった物はわきへ動きます。どちらも⌘Zで取り消せます。

### デスクパーティション

- **パーティション**：机の奥に沿ったフェルトのパーティションで、モニターの横は一段高くなっています。ほかの物と同じようにしまえ、付箋はそのまま待っています。
- **付箋**：付箋キューブをクリックすると新しい付箋、ドラッグすると一枚はがせます。フェルトのどこへでもドラッグでき、読める位置に合わせて止まります。付箋をクリックするとMemos（メモ）ウインドウで編集できます（日本語入力もMacのほかの場所と同じように使えます）。6色、日付、Bring to Front（最前面へ）が選べ、くずかごに落とすとはがせます（⌘Zで戻ります）。最大24枚。ポインタを重ねると読めます（暗がりでは光が届いているものだけ）。
- **日めくりメモ**：デスクライトの下にある、今日の日付の一枚です。クリックして書き、ドラッグでちぎるとその日の日付の付箋になります。
- **壁のカレンダー**：メモ・日付付きの付箋・D-Dayのある日に印が付き、日付をクリックするとその日が開きます。Memosウインドウで月全体を見られます。
- **メモクリップ**：パーティションにファイルを置くと、カードとして留められます（5つまで）。ほかの隠し場所と同じく、変わるのはレイアウトだけです。
- **D-Dayカードとクリップライト**：MemosウインドウのカレンダーでD-Dayを決めると、カードに「D-12」「D-DAY」「D+3」と表示されます。クリップライトをクリックすると、夜にパーティションの右側を照らします。
- **テキストファイルとして保存**：付箋のメニューのSave as Text File on Desktop（日めくりメモではSave Today's Memo as Text File）か、Memosウインドウのボタンで、デスクトップフォルダに新しい.txtファイルができ、パーティションに留められます。
- **大切に保管**：メモは状態フォルダの`memos.json`に別に保存され、セーフモードのReset Layoutやフォルダの切り替えでも残ります。

### フォトフレーム

- **自分の写真を壁に**：壁の棚の上にある額入りのプリントを、自分の写真に替えられます。右クリック ▸ Choose Photo…（写真を選択）、モニターの画像をドラッグして重ねる、画像のメニューのHang in Picture Frame（フォトフレームに飾る）、またはFinderから写真をフレームにドロップ（ほかのディスプレイの壁のフレームにも）。写真は部屋の46色で26 × 34ピクセルに描かれ、夜は部屋と一緒に暗くなり、ほかのディスプレイの壁にも飾られます。
- **読むだけ**：写真は一度読むだけで、移動・コピー・変更はせず、名前も表示しません。フレームは自分用のピクセルの写しを状態フォルダの`frame.json`に保存し、セーフモードのReset Layoutやフォルダの切り替えでも残ります。⌘Zで飾る前に戻せ、Remove Photo（写真を外す）で元のプリントに戻ります。

### デスクマット

- **布**：上はフェルト、下はゴムの布製マットをシミュレーションしています。上にはキーボードが載っていて、マットを押さえ、マットと一緒に回ります。
- **マットの下**：マットにドロップしたファイルは下に滑り込み、ふくらみを残します。ふくらみは積み重なる数に応じて大きくなります（近くにある山どうしは1つのふくらみを共有します）。布が覆っているものはすべて隠れるので、散らばった山の上にマットを滑らせても隠せます。
- **めくる・折る**：端や角を内側へドラッグすると持ち上がり、下にあった山が立ち上がって取り出せます。放す前に少し止めると、しばらく持ち上がったままになります。真ん中を越えて引くと、折りたたまれたままになります（折り返しをダブルクリックすると広がります）。
- **持ち運びとしわ**：マットをドラッグして持ち運べます。速く運ぶとしわが残り、アプリを再起動しても消えません。角を外側へ引っぱるか、端をダブルクリックするか、Smooth Desk Matを選ぶと平らになります。
- **回転とサイズ**：⌥を押しながら角をドラッグするとサイズと向きが変わり（⇧で15°刻み）、⌥を押しながら中央をドラッグすると、しわを作らずに滑らせられます。メニューも使えます：Rotate（±15°、Straighten）、Size（Small、Medium、Large）、Reset Mat。デスクに収まる範囲でしか回転・拡大しません。
- **Peek Under**：クリックした場所にいちばん近い山の上で、マットを少しの間めくります。**List Items Under Mat ▸** で名前を選ぶと、そのファイルがモニターに戻ります。
- **Flatモード**（Settings ▸ Desk mat、またはReduce motion）：ふくらみと隠す機能はそのままで、マットは持ち上がりません。
- **ブラシ**：ドラッグして、山をマットの下へ、またはデスクの端の外へ押し出します。ダブルクリックで定位置に戻ります。デスクの上で2本指で横にスクロールすると、見えないブラシ「スクロールほうき」になります。

### 物理演算

- **デスクの上の山**：デスクに置いたファイルは山（個数の札付き）になり、滑り、ぶつかり、積み重なります。
- **放り投げ**：ファイルを速く動かしながら放すと、弧を描いて飛んでいきます。デスクの端を越えて床へ、あるいはくずかごの中へ。床に落ちたファイルも見えていて、拾い上げられます。
- **デスクを叩く**：デスクの手前の縁をダブルクリックすると、山が跳ね、ペン立て・モニター・スマートフォンが揺れ、マットが波打ち、少し開いていた引き出しがパタンと閉まります。場所が変わるファイルはありません。
- **Clear the Desk**：ワンアクションで、モニターが消え、スマートフォンが伏せられ、引き出しが閉まり、ブラシが散らばった山と床のファイルをすべてマットの下に掃き込みます。「TIDY!」⌘Zを1回押せば、すべて元どおりです。
- **小さな仕掛け**：鉢植えをつつくと揺れ、キーをクリックすると押し込まれます（実際に打っている内容は決して表示しません）。
- **Reduce motion**：放ったファイルはポンと一瞬で着地し、何も揺れず、ブラウン管はしぼむ代わりにフェードアウトします。

### 照明

- **時間帯**：Lights ▸ Autoは時計に合わせて昼、夕暮れ、夜と移り変わり、窓の外の空も変わります（流れる雲、夜は星と月）。Day、Night、Lamp Onlyを選ぶと、その状態で固定されます。
- **部屋の照明とデスクライト**：壁のスイッチやデスクライトをクリックします。デスクライトはデスクに暖かな光だまりを落とし、モニターと表向きのスマートフォンはひんやりした光を放ちます。
- **Lamp Only**：部屋の照明を消し、デスクライトをつけた状態です。デスクライトの光だまりと画面の光が届くところしか見えません。暗がりのファイルは選べないシルエットになるので、デスクライトが懐中電灯の役目をします。
- **時計のプレビュー**：時計の分針をドラッグすると、ほかの時間帯の様子が見られます。放すと元に戻ります（真夜中を越えてプレビューすると、カレンダーもめくれます）。

### ファイルと検索

- **Find Item…**（⌘F）：すべてのファイルとその場所を、検索付きで一覧します。Open、Quick Look、Show in Finder、Take Out、そして**Show on Desk**があります。Show on Deskはファイルを隠しているものを開き（モニターの電源を入れる、ページを切り替える、引き出しを開ける、椅子を脇へ転がす、スマートフォンを表に返す、マットの下をのぞく）、ファイルを指し示します。
- **Take Everything Out**：すべてのファイルがモニターに戻ります。⌘Zを1回押せば取り消せます。
- **ふだんのコマンド**：Open（ダブルクリック、⌘O）、Quick Look（Space）、Show in Finder、Copy（⌘C）、Open Desktop Folder in Finder。
- **ファイル操作は頼んだときだけ**：Move to Trash（メニューから。キーボードショートカットはありません）、Empty Wastebasket…、Finderからのファイルのドロップ（フォルダへ移動。別のディスクからの場合や⌥を押しているときはコピー。アプリはエイリアスになり、元の場所に残ります。同じ名前があれば " 2" を付けます）、ほかのアプリ、メール、Dockのゴミ箱へのドラッグ、Eject、Save as Text File on Desktop（新しいファイルを作るだけ）。ロックされたファイルが移動されてくることはありません。
- **取り消し**：⌘Zで直近20ステップまで取り消せます（⌘⇧Zはレイアウトの操作をやり直します）。Deskterior自身のファイル操作も対象で、ゴミ箱に入れたファイルは同じ場所に戻り、ドロップしたファイルは元の場所に戻り、保存したテキストファイルはゴミ箱へ移ります。Ejectとほかのアプリへのドラッグは取り消せません。ファイル操作はすべて`operations.log`に記録されます。
- **ドライブハブ**：マウントされたドライブが、USBメモリ、ディスク、サーバの姿でハブに差し込まれます（4スロット、それを超えると「+n」の札）。ダブルクリックで開き、メニューからOpen、Show in Finder、Ejectを選べます。ドライブにファイルをドロップするとBONK。ドライブへのコピーはFinderの仕事です。
- **安全第一**：隠すのはレイアウトだけで、何も削除せず、何も上書きしません。[ファイルは安全です](#ファイルは安全です)を参照してください。

### システム

- **Finderを覆うだけで、何も変えません**：デスクはFinderのデスクトップアイコンのすぐ上にあるウインドウで、Finderの設定は読み取るだけです。Deskteriorを終了するかPause Deskを使えば、元のデスクトップが戻ります。
- **メニューバーアイコンと壁のメニュー**：Dockアイコンはありません。デスクのコマンドはメニューバーアイコンと、何もない壁の右クリックメニューにあり、各オブジェクトにもそれぞれ右クリックメニューがあります。
- **すべてのディスプレイに**：絵は整数倍率（Chunky、Normal、Fineのピクセル）で描かれ、部屋はどんな画面でも埋めるように広がります。縦に長いディスプレイや縦置きのディスプレイには、梁のある天井、棚、アートプリント、吊り下げの植物が加わります。ほかのディスプレイにはおそろいの壁を表示でき（そこにドロップしたファイルはモニターへ行きます）、デスクを表示するディスプレイはSettingsで選べます。
- **Peek DeskとPause Desk**：Peekはデスクをウインドウの上に浮かべます（戻るには× DoneかEsc。⌃⌥⌘Dのショートカットは任意で、初期設定ではオフ）。Pauseはデスクをしまい、再開するまでFinderのデスクトップを表示します。
- **じゃまをしません**：フルスクリーンのアプリの下、ディスプレイのスリープ中、画面のロック中、ユーザの切り替え中はデスクが一時停止し、設定すればバッテリー駆動中も止まります（使うまでは静止画）。何も動いていないときは描画を止め、低電力モードでは毎秒30フレームに抑えます。デスクトップのウィジェットがモニターや引き出しにかからないよう、部屋を少しずらします。
- **デスクを覚えています**：レイアウトは随時保存され、1時間ごと、毎日、毎週のバックアップが残ります。映すフォルダごとに別のレイアウトを持ち、レイアウトファイルが壊れていたら修復するか、バックアップに置き換えます。
- **[設定](#設定)**：Lights、Reduce motion、Desk mat、Pixel size、Mirrored folder、Peek Desk shortcut、Launch at login、Pause on battery、ディスプレイ、Language、Leftover copies（コピーが中断されたあと）、About & Credits。
- **[セーフモード](#セーフモード)**：起動時に⌥を押したままにすると、通常どおり起動する、レイアウトをリセットする（古いレイアウトはバックアップとして保存）、状態フォルダを開く、から選べます。
- **アクセシビリティ**：VoiceOverはすべてのファイルとコントロールを一覧し、メッセージを読み上げます。Find Item…ですべてのファイルにたどり着けます。Reduce motion（初期設定ではシステムに従う）を使うと、揺れ、ちらつき、飛ぶ動きが別の表現に置き換わります。
- **言語**：メニュー、カード、メッセージ、ウインドウ、設定は英語と韓国語に対応しています。Language ▸ Systemは、優先する言語のうちDeskteriorが対応している最初の言語を選び、それ以外の言語では英語で表示します。
- **プライバシー**：ネットワークには一切接続せず、分析も、テレメトリも、アップデータもありません。必要な権限はデスクトップフォルダへのアクセスだけです。
- **パッケージ**：Appleシリコン用とIntel用を1つにしたユニバーサルアプリで、macOS 14以降で動作し、Command Line Toolsでビルドしています（Xcodeは不要）。リリースはアドホック署名（公証なし）で、SHA-256チェックサムとビルドの来歴証明（attestation）が付きます。CIでは1,000件以上のテストを実行しています。

## 隠し場所の使い方

| 場所 | 隠し方 | 取り出し方 |
|---|---|---|
| **モニター** ⏻ / **INPUT** / **AV** | 電源ボタンを押すと、昔のブラウン管のように画面がしぼんで消え、すべてのファイルが隠れます。電源が切れている間にファイルが届くと、琥珀色のLEDと「+N」バッジが点灯します。INPUTはページ（HDMI 1、2…、45個ごとに1ページ）と、常に空のページであるAVを順に切り替えます。 | もう一度電源を押すか、別の入力を選びます。 |
| **モニター台の引き出し**（2つ）と**小物棚** | 閉じた引き出しにファイルをドロップすると、引き出しが開いて受け取り、閉まります。入れすぎた引き出しは少し開いたままになり、詰まった引き出しはそれ以上受け付けません（BONK）。小物棚は半分しか隠しません。ぼんやりしたシルエットが見え、ポインタを重ねると名前が出ます。 | 取っ手をクリックするかドラッグします。閉じた引き出しの上でスクロールすると、中をのぞけます。小さなアイコンをドラッグして取り出します。 |
| **ファイルキャビネット**（引き出し3段）と**椅子** | モニター台の引き出しと同じです。いちばん下の引き出しは、色分けされたフォルダタブで書類を整理します。一度に開く引き出しは1つだけです。 | 椅子がじゃまをしていると、引き出しは少ししか開きません。椅子が脇へ転がるので、次に引けば開きます。 |
| **スマートフォンスタンド** | 表向きのスマートフォンにファイルをドロップすると、アプリアイコンになります。スマートフォンをクリックすると伏せられます（表向きのスマートフォンは、本物のように夜に光ります）。 | もう一度クリックするか、メニューからTurn Face Upを選びます。 |
| **ペン立て** | ファイルを入れるとペンになります。キャップの色で種類がわかります。 | 最後に入れたペンをペン立てから引き抜きます。ペンが3本以上入ったペン立てを素早くはじくと倒れて、ペンがデスクにこぼれます。クリックすると起き上がります。 |
| **くずかご** | ファイルをドロップするか、放り込みます。丸めて隠すだけで、**削除はされません**。 | いちばん上の紙をドラッグして取り出すか、ふちを横にドラッグしてくずかごを倒します。Empty Wastebasket…は、中身の一覧を表示して確認したあとで、それらをmacOSのゴミ箱に移します。 |
| **デスクマット**と**ブラシ** | マットにファイルをドロップすると下に滑り込み、ふくらみが残ります。高く積むほど、ふくらみも大きくなります。ブラシで、またはデスクの上で2本指で横にスクロールして、山を押し込むこともできます。 | 端や角をめくると、下にあった山が立ち上がって取り出せます。右クリック ▸ Peek Underでも見られます。Flatのマット（またはReduce motion）では、マットは持ち上がりません。マットを右クリック ▸ List Items Under Mat ▸ で名前を選ぶとそのファイルがモニターに戻り、Find Item…（⌘F）も使えます。 |
| **メモクリップ**（パーティション） | パーティションにファイルを置くと、アイコンのカードとして留まります。隠すのではなく、見えるところに置いておく場所です。 | カードをドラッグで外すか、クリップのメニューからTake All Outを選びます。 |
| **デスクライト**と**Lamp Only** | 夜に部屋の照明を消してデスクライトだけをつけると、デスクライトの光だまり、モニターの光、スマートフォンの光が届くところしか見えません。暗がりのファイルはシルエットになり、名前も出ず、クリックもできません。 | デスクライトの光だまりや、モニター・表向きのスマートフォンの光の中にあるファイルは選べます。部屋の照明をつけ直すか、Lights ▸ Autoを選びます。 |
| **ドライブハブ** | DeskteriorはFinderのドライブアイコンも覆うので、マウントされたドライブはデスクのハブに差し込まれた姿で現れます。 | ダブルクリックで開きます。取り出しは、ドライブのメニューのEjectから。 |
| **Clear the Desk** | メニュー項目1つで、モニターが消え、スマートフォンが伏せられ、引き出しが閉まり、ブラシが散らばった山をすべてマットの下に掃き込みます。「TIDY!」 | ⌘Zを1回押せば、すべてが正確に元どおりになります。 |
| **Find Item…**（⌘F） | — | すべてのファイルとその場所を一覧します（検索付き）。**Show on Desk**はファイルを隠しているものを開いてファイルを指し示し、**Take Out**はモニターに戻します。メニューの**Take Everything Out**は、すべてを戻します。 |
| **Peek Desk** / **Pause Desk** | — | Peek Deskは、デスクを一時的にウインドウの上に持ち上げます（戻るには× DoneかEsc。ショートカット⌃⌥⌘Dは任意）。Pause Deskはデスクをしまい、再開するまでFinder本来のデスクトップを表示します。 |

隠したものが勝手に出てくることはありません。叩いても、バタンと閉めても、入れすぎても、入れ物が空になることはありません。隠したファイルがふたたび見えるのは、入れ物を開ける、マットをめくるか動かす、スマートフォンを返す、ペン立てやくずかごを倒す、入力を切り替える、またはメニュー、Find Item…、Show on Desk、Take Everything Outを使ったときだけです。

**Put Away**（しまう）は物を丸ごと部屋から片付けます（右クリック、Put Away ▸、Arrange Desk…）。しまった場所にファイルは残りません：先にモニターへ出します。Bring Back ▸で戻します。

| 操作 | できること |
|---|---|
| **クリック** | ファイルを選択します（⌘-クリックで追加・解除、空いた画面でドラッグすると複数選択、⌘Aでそのページを全選択）。スイッチの切り替えやボタンを押すのもクリックです：電源ボタン、INPUT、デスクライト、部屋の照明スイッチ、引き出しの取っ手、スマートフォン。パーティションでは、付箋（編集）、付箋キューブ（新しい付箋）、日めくりメモ、壁のカレンダーの日付、クリップライトもクリックします。壁では、空のフォトフレーム（Choose Photo…）をクリックします。 |

## ファイルは安全です

- **隠すのはレイアウトだけ**：引き出しの中、マットの下、くずかごの中にあるファイルも、デスクトップフォルダの中にそのまま、手つかずで残っています。Finder、Spotlight、ほかのアプリからも、以前とまったく同じに見えます。Deskteriorが覚えているのは、どこに置いたかだけです。Put Awayとメモクリップも、変えるのはレイアウトだけです。フォトフレームに写真を飾っても、写真は読むだけです。
- **ファイルが変更されるのは、あなたがはっきり頼んだときだけ**です。次の操作に限られます：
  - ファイルの右クリックメニューの**Move to Trash**（キーボードショートカットはありません）
  - **Empty Wastebasket…**（名前の一覧を表示して確認したあと）
  - Finderからデスクへのファイルのドロップ（デスクトップフォルダへ移動。別のディスクから来た場合や、⌥を押しているときはコピー。アプリはエイリアスを作るだけで元の場所に残し、⌘⌥を押すと何でもエイリアスに）
  - ほかのアプリへのファイルのドラッグ（そのアプリは、Finderからドラッグされたときと同じように扱います。Dockのゴミ箱にドロップしてDockが移動しなかった場合は、Deskterior自身がゴミ箱に移します）
  - ドライブのメニューの**Eject**
  - 付箋や日めくりメモのメニューの**Save as Text File on Desktop**（新しいファイルを作るだけで、既存のファイルは決して変えません）
  - Settings ▸ Leftover copiesの**Move to Trash**（コピーが中断されたあとにだけ表示されます。下記参照）
- **ゴミ箱に移すだけで、削除はしません**：DeskteriorはファイルをmacOSのゴミ箱に移すだけで、何も削除しません。ファイルを上書きすることもありません。同じ名前があれば " 2"、" 3"…を付けます。
- **ロックされたファイルはそのまま**：ロックされたファイルをデスクにドロップしても、デスクトップフォルダには移動しません（代わりにコピーするには⌥を押したままにします）。コピーの途中で終了するなどしてコピーが中断されると、デスクトップフォルダに隠しフォルダ`.deskterior-partial-…`が残ることがあります（macOSがそのディスクに一時フォルダを用意しない場合のみ）。それが残っている間、Deskteriorは起動するたびに一度知らせ、Settings ▸ Leftover copiesに表示します（Show in Finder、Move to Trash）が、自分で削除することはありません。
- **取り消し**：⌘Zはレイアウトの変更と、Deskterior自身のファイル操作（Move to Trash、Empty Wastebasket…、デスクへのドロップ、Save as Text File）を取り消します。ゴミ箱に入れたファイルはデスクの同じ場所に戻り、ドロップしたファイルは元の場所に戻ります（コピー、エイリアス、保存したテキストファイルはゴミ箱へ。保存後に変更したテキストファイルはそのまま残します）。Ejectとほかのアプリへのドラッグは取り消せません。ただし、Deskteriorが実行したDockのゴミ箱へのドラッグは例外です。macOSがDeskteriorにゴミ箱へのアクセスを許さない場合はそう知らせるので、Finderの「戻す」を使えます。
- **Finderには手を加えません**：デスクはFinderのデスクトップアイコンのすぐ上にあるウインドウです。アイコンを覆っているだけで、Finderの設定を変えて隠しているわけではありません（Finderの設定は読み取るだけです）。Deskteriorを終了するかPause Deskを使えば、いつものデスクトップが戻ります。
- **プライバシー**：ネットワークには一切接続せず、分析もテレメトリもありません。必要な権限はデスクトップフォルダへのアクセスだけです（ダウンロード、書類、ほかのドライブからファイルをドロップするときに、macOSが一度確認することがあります）。アクセシビリティ、画面収録、入力監視の権限は不要です。ファイル操作はすべて、状態フォルダの`operations.log`に記録されます。

## インストール

Deskteriorは無料で、Appleの公証（notarization）を受けていません（有料のデベロッパアカウントが必要なため）。リリースはアドホック署名なので、ダウンロードしたバージョンごとに、最初の起動をmacOSが一度ブロックします。これは想定どおりの動作です。

1. [最新リリース](../../releases/latest)から**Deskterior-*バージョン*.zip**をダウンロードし、ダブルクリックして展開します。
2. **まず`Deskterior.app`を「アプリケーション」フォルダに移動してください**。ダウンロードフォルダから直接開くと、macOSはそれを隠された読み取り専用のコピー（App Translocation）から実行するため、権限を忘れてしまうことがあります。その場合はDeskteriorが気づいて、移動するよう案内します。
3. Deskteriorを開きます。
   - **macOS 15 Sequoia以降**：Deskteriorを開けなかったというダイアログが表示されます。**完了**をクリックします（**ゴミ箱に入れる**ではありません）。**システム設定 ▸ プライバシーとセキュリティ**を開き、下にスクロールして**セキュリティ**のところで、Deskteriorについてのメッセージの横にある**このまま開く**をクリックします（表示されるのは約1時間です）。続けて**このまま開く**をクリックし、パスワードかTouch IDで確認します。Controlキーを押しながらクリックして「開く」を選んでも、この手順はもう省略できません。
   - **macOS 14 Sonoma**：Controlキーを押しながらアプリをクリック（または右クリック）して**開く**を選び、もう一度**開く**をクリックします。「プライバシーとセキュリティ」の「このまま開く」ボタンでもかまいません。
4. アップデートのたびに、この手順を繰り返してください。アドホック署名のビルドなので、アップデートのあとにデスクトップフォルダへのアクセスをmacOSがもう一度尋ねることもあります。

ダウンロードしたファイルを検証するには、両方のファイルをダウンロードしたフォルダでターミナルを開き（通常は`cd ~/Downloads`）、同じリリースの`.sha256`ファイルと照合します。または、このリポジトリのリリースワークフローでビルドされたことを確認します（GitHub CLIを使います。OWNERは、このページのURLにあるアカウント名に置き換えてください）：

```sh
shasum -a 256 -c Deskterior-0.3.0.zip.sha256
gh attestation verify Deskterior-0.3.0.zip --repo OWNER/deskterior
```

## 初回起動

1. ウェルカムウインドウがデスクを紹介します。モニターには**PRESS ⏻ TO CONNECT DESKTOP**と表示されます。
2. モニターの電源ボタン⏻をクリックします。macOSが、Deskteriorに「デスクトップ」フォルダ内のファイルへのアクセスを許可するかどうかを尋ねるので、**許可**をクリックします。ファイルがモニターに表示されます。Deskteriorがアクセスを求めるのは、⏻を押したあとだけです。
3. **許可しない**をクリックした場合は、モニターに**NO SIGNAL**と2つのボタンが表示されます：**Open Settings**（システム設定 ▸ プライバシーとセキュリティ ▸ ファイルとフォルダ。ここでDeskteriorの「デスクトップフォルダ」をオンにできます）と、**Choose Folder…**（デスクトップフォルダを選びます。選ぶとアクセスが許可されます）です。

## セーフモード

Deskteriorを起動するときに、**⌥（Option）キー**を押したままにします。デスクより先にSafe Modeのウインドウが表示され、この時点ではまだ何も変更されていません：

- **Start Normally**（通常どおり起動）
- **Reset Layout…**：すべてのファイルがモニターに戻り、しまった物もすべて戻ります。元のレイアウトはバックアップとして状態フォルダに保存されます（ファイルは削除されません）。付箋とメモ、フォトフレームの写真は消えません。
- **Open State Folder**（状態フォルダを開く）
- **Quit**（終了）

デスクが反応しなくなったときは、ターミナルで`killall Deskterior`を実行すれば、すぐにデスクが消えて、いつものデスクトップが戻ります。ファイルにはもともと一切手を加えていません。

## アンインストール

1. **Launch at login**をオンにしていた場合は、Settingsでオフにします。
2. Deskteriorを終了します（メニューバーアイコン ▸ Quit Deskterior）。
3. 必要なら、レイアウト、付箋とメモ、フォトフレームの写真、アイコンキャッシュ、設定、プライバシーの権限も削除します。これらはアプリのバンドルIDにちなんだ名前なので、アプリを削除する前にIDを読み取ります。次のブロック全体を、一度にターミナルに貼り付けてください：

   ```sh
   ID="$(defaults read /Applications/Deskterior.app/Contents/Info CFBundleIdentifier)" &&
   case "$ID" in io.github.*.deskterior | io.github.deskterior.dev)
     rm -rf ~/Library/Application\ Support/"$ID" ~/Library/Caches/"$ID"
     defaults delete "$ID"
     tccutil reset All "$ID"
   esac
   ```

   最初の行でエラーが表示されたら、そこで止めてください。Deskteriorが/Applicationsにありません。このブロックはレイアウト、そのバックアップ、付箋とメモ（`memos.json`）、フォトフレームの写真（`frame.json`）、`operations.log`（Application Support）、アイコンキャッシュ（Caches）、設定（`defaults`）、デスクトップフォルダの権限（`tccutil`）を削除します。バンドルIDがDeskteriorのものでなければ、何もしません。

4. `Deskterior.app`をゴミ箱に入れます。

macOS 15.6以降と、Xcode 26用のCommand Line Tools（Swift 6.2、`xcode-select --install`）が必要です。Xcodeは不要です。ビルドしたアプリはmacOS 14以降で動作します。このリポジトリのクローンで、次のコマンドを使います：

| コマンド | 内容 |
|---|---|
| `make build` | `swift build` |
| `make test` | テストスイート、CI と同じ実行方法（`scripts/ci-test.sh`） |
| `make lint` | ファイル安全性のlint（`scripts/check-file-safety.sh`） |
| `make app` | このMacのプロセッサ用の`build/Deskterior.app`、アドホック署名（`VERSION=0.3.0`でバージョンを指定） |
| `make universal` | 同じものを、AppleシリコンとIntelの両対応の1つのアプリとして |
| `make install` | `make app`のあと、アプリを/Applicationsにコピー |
| `make run` | サンプルファイルを入れた新しい作業用フォルダで、デスクをウインドウ内で実行 |
| `make gif` | `Demos/hero.json`を収録して`docs/media`を作り直す（ffmpegが必要） |

自分でビルドしたアプリには検疫属性が付かないので、Gatekeeperに止められません。バンドルIDはクローンのGitHubリモートから決まります（リリースと同じ`io.github.OWNER.deskterior`）。リモートがない場合は、開発用のID`io.github.deskterior.dev`になります。無料の自己署名証明書で署名すると、再ビルドしてもデスクトップの権限が保たれます：[docs/SIGNING.md](docs/SIGNING.md)を参照してください。

開発時の実行が本物のデスクトップに触れることはありません。作業用フォルダが必要で、本物のデスクトップやその中にあるものを指定すると拒否されます（終了コード64）。スクリプト化されたデモは、新しく作ったフィクスチャのフォルダでヘッドレスで（画面に表示せずに）動き、PNGを書き出します（このデモは`.build/demo-out/10-clear-desk`へ）。最後の2行は、`make run`がしていることです：

```sh
scripts/run-demo.sh 10-clear-desk
FIX="$(mktemp -d)"; scripts/make-fixture-desktop.sh "$FIX/desk"
swift run Deskterior --windowed --desktop-folder "$FIX/desk" --state-dir "$FIX/state"
```

詳しくは（いずれも英語）：[docs/DESIGN.md](docs/DESIGN.md)（設計）、[docs/DEMOS.md](docs/DEMOS.md)（デモスクリプト）、[docs/SPIKES.md](docs/SPIKES.md)（プラットフォームの検証）、[CHANGELOG.md](CHANGELOG.md)（変更履歴）。

## 動作環境

- macOS 14 Sonoma以降
- AppleシリコンまたはIntelのMac（1つのユニバーサルアプリ）
- デスクトップフォルダの読み取り権限（最初に⏻を押したときに尋ねられます）

## 既知の制限

- **公証を受けていません**：ダウンロードしたバージョンごとに上記の「このまま開く」の手順が必要で、アップデートのあとにmacOSがデスクトップへのアクセスをもう一度尋ねることがあります（アドホック署名はビルドごとに変わるため）。
- **テストしたのは1台のMacだけです**（macOS 26のMacBook Air M2）。macOS 14と15向けにもビルドしていますが、実際に動かしたことはなく、アプリのIntel部分もIntel Macでは動かしていません。
- **人の手で確かめる必要があるプラットフォームの動作が残っています**。自動化では確認できないものです：ほかのアプリが前面にあるときのクリックとホバー、デスクをクリックしたあとのQuick Lookと⌘Z、フルスクリーンのアプリの下での一時停止、Finder・メール・Dockのゴミ箱へのドラッグ、本物のゴミ箱を経由した取り消し、ダウンロードフォルダからのドロップ。[docs/SPIKES.md](docs/SPIKES.md)を参照してください。
- 壁紙をクリックしてデスクトップを表示する機能（macOS 14以降）は、デスクの上では使えません。「デスクトップを表示」、Peek Desk、Pause Deskを使ってください。
- デスクトップのウィジェットはデスクより上に表示されます。Deskteriorは可能な範囲で部屋を少しずらし、ウィジェットがモニターや引き出しにかからないようにします。
- 解像度をスケーリングしたディスプレイモードでは、ピクセルが少しぼやけます。
- **exFAT**のドライブにあるフォルダを映している場合、ドロップはできず、ゴミ箱に入れたファイルを⌘Zでそこへ戻すこともできません。Deskteriorはすべての移動に「上書きしないリネーム」を使いますが、exFATはこれに対応していないため、操作を拒否して何も変更しません。FAT32とAPFSでは動作します。
- Finder本来のデスクトップは下に残っています。Deskteriorが覆う前にFinderでデスクトップのアイコンを選択していた場合、Finderで⌘⌫を押すと、それらがゴミ箱に移動することがあります（Finderの取り消しで戻せます）。
- カレンダーは部屋のものです：カレンダーAppは読み書きせず、メモはこのMac（`memos.json`）にだけ保存されます。
- 付箋は机のあるディスプレイにだけ表示され、ほかのディスプレイの壁には出ません。
- 韓国語の設定でも、画面の一部は英語のままです：ツールチップ、VoiceOverが読み上げるデスクのオブジェクト名、AV入力のNO SIGNALロゴ、BONK、SWISH!、TIDY!（パーティション、カレンダー、フォトフレームのツールチップは韓国語で表示されます）。

# Deskterior (데스크테리어)

[English](README.md) · **한국어**

<img src="docs/media/hero.gif" width="588" alt="Deskterior: 픽셀 아트 모니터에 놓인 파일들. 하나는 받침대 서랍에 넣고, 한 무더기는 빗자루로 책상 매트 밑에 쓸어 넣고, 매트 가장자리를 들춰 파일 하나를 꺼낸 뒤, 모니터를 끄고, 시계 분침을 돌려 밤으로 만든 다음, 방 조명을 끄고 책상 스탠드만 켜 둔 채 모니터를 다시 켠 방">

<sub>그림에는 책상에 내장된 파일 아이콘을 썼습니다. 실제로는 파일마다 자기 아이콘이나 미리보기가 픽셀로 나옵니다.</sub>

**Mac 바탕화면에 사는 픽셀 아트 책상입니다.** Deskterior는 바탕화면을 아늑한 작은 방으로 덮고, 바탕화면 폴더의
파일을 책상 위 모니터에 아이콘으로 띄웁니다. 정리는 진짜 책상에서 하듯이 하면 됩니다. 모니터 받침대 서랍이나
서랍장에 넣고, 휴대폰 거치대나 펜꽂이에 꽂고, 쓰레기통에 던져 넣고, 빗자루로 천 책상 매트 밑에 쓸어 넣거나,
그냥 모니터 전원 버튼을 누르세요. 숨기기는 배치만 바꿉니다. 파일은 제자리에 그대로 있고, 직접 요청할 때만
바뀝니다.

## 숨기는 곳

<img src="docs/media/hiding.png" width="600" alt="낮에 숨기는 곳을 쓰는 모습을 가까이서 본 그림: 사진 세 장이 든 열린 받침대 서랍, 메모가 든 받침대 칸, 펜 두 자루가 꽂힌 펜꽂이, 앱 아이콘 세 개가 뜬 휴대폰, 폴더 탭이 보이게 열린 서랍장 맨 아래 서류 칸">

| 장소 | 숨기는 법 | 다시 꺼내는 법 |
|---|---|---|
| **모니터** ⏻ / **INPUT** / **AV** | 전원 버튼을 누르면 옛날 브라운관처럼 화면이 한 줄로 오므라들며 모든 파일이 숨습니다. 꺼져 있는 동안 새 파일이 생기면 주황색 LED와 "+N" 배지가 알려 줍니다. INPUT은 페이지(HDMI 1, 2…, 45개마다 한 페이지)와 늘 비어 있는 AV를 차례로 바꿉니다. | 전원을 다시 누르거나 다른 입력을 고르세요. |
| **받침대 서랍**(2개)과 **받침대 칸** | 닫힌 서랍에 파일을 놓으면 서랍이 열려 덥석 삼키고 닫힙니다. 너무 많이 넣으면 살짝 열린 채로 있고, 꽉 끼면 더는 들어가지 않습니다(BONK). 받침대 칸은 반만 숨깁니다. 어렴풋한 실루엣이 보이고 마우스를 올리면 이름이 나옵니다. | 손잡이를 클릭하거나 끌어서 여세요. 닫힌 서랍 위에서 스크롤하면 살짝 들여다볼 수 있습니다. 작은 아이콘을 끌어 꺼냅니다. |
| **서랍장**(3칸)과 **의자** | 받침대 서랍과 같습니다. 맨 아래 서류 칸은 색깔 폴더 탭으로 정리됩니다. 한 번에 한 칸만 열립니다. | 의자가 막고 있으면 서랍이 조금만 열리는데, 그때 의자가 옆으로 굴러가서 다음번엔 열립니다. |
| **휴대폰 거치대** | 화면이 위를 향한 휴대폰에 파일을 놓으면 앱 아이콘이 됩니다. 휴대폰을 클릭하면 엎어집니다(진짜 휴대폰처럼 화면이 위를 향하면 밤에 빛이 납니다). | 다시 클릭하거나 메뉴에서 ‘화면이 위로 오게 뒤집기’를 고르세요. |
| **펜꽂이** | 파일을 넣으면 펜이 됩니다. 뚜껑 색으로 종류를 알 수 있습니다. | 마지막 펜을 끌어 뽑으세요. 펜이 셋 이상 든 펜꽂이를 빠르게 휙 밀면 넘어지면서 펜이 책상 위로 쏟아지고, 클릭하면 다시 섭니다. |
| **쓰레기통** | 파일을 넣거나 던져 넣으세요. 구겨질 뿐 **지워지지 않습니다**. | 맨 위 종이 뭉치를 끌어 꺼내거나, 테두리를 옆으로 끌어 쓰레기통을 넘어뜨리세요. ‘쓰레기통 비우기…’는 이름 목록을 보여 주고 확인을 받은 뒤에야 macOS 휴지통으로 옮깁니다. |
| **책상 매트**와 **빗자루** | 매트 위에 파일을 놓으면 밑으로 쏙 들어가고 볼록한 자국만 남습니다. 많이 쌓일수록 더 볼록해집니다. 빗자루로, 또는 책상 위에서 두 손가락으로 옆으로 스크롤해서 더미를 밀어 넣을 수도 있습니다. | 가장자리나 모서리를 들추면 밑에 있던 더미가 일어서서 꺼낼 수 있습니다. 오른쪽 클릭 ▸ ‘밑 들춰 보기’도 됩니다. 매트가 ‘평평하게’일 때(또는 동작 줄이기를 켰을 때)는 매트가 들리지 않습니다. 매트를 오른쪽 클릭 ▸ ‘매트 밑 항목 보기’ ▸ 이름을 고르면 그 파일이 모니터로 돌아오고, ‘항목 찾기…’(⌘F)도 됩니다. |
| **스탠드**와 **스탠드만** | 밤에 방 조명을 끄고 책상 스탠드만 켜 두면, 스탠드 불빛과 모니터·휴대폰 화면 빛이 닿는 곳만 보입니다. 어둠 속 파일은 실루엣이라 이름도 안 보이고 클릭도 안 됩니다. | 스탠드를 손전등처럼 쓰거나, 방 조명을 켜거나, 조명 ▸ 자동을 고르세요. |
| **드라이브 허브** | 책상이 Finder의 드라이브 아이콘까지 덮기 때문에, 연결된 드라이브는 책상 위 허브에 꽂혀 나타납니다. | 더블클릭하면 열립니다. 추출은 드라이브 메뉴에서 합니다. |
| **책상 치우기** | 메뉴 하나로 모니터가 꺼지고, 휴대폰이 엎어지고, 서랍이 닫히고, 빗자루가 흩어진 더미를 모두 매트 밑에 쓸어 넣습니다. "TIDY!" | ⌘Z 한 번이면 모든 게 그대로 돌아옵니다. |
| **항목 찾기…** (⌘F) | — | 모든 파일과 그 위치를 보여 주고 검색도 됩니다. ‘책상에서 보기’는 숨긴 곳을 열어 파일을 짚어 주고, ‘꺼내기’는 모니터로 되돌립니다. 메뉴의 ‘모든 파일 꺼내기’는 전부 모니터로 돌려놓습니다. |
| **책상 엿보기** / **책상 일시 정지** | — | 책상 엿보기는 잠깐 책상을 창들 위로 띄웁니다(× 완료나 Esc로 돌아가기, 단축키 ⌃⌥⌘D는 선택). 책상 일시 정지는 책상을 치우고 다시 켤 때까지 Finder의 원래 바탕화면을 보여 줍니다. |

저절로 튀어나오는 건 없습니다. 책상을 두드리거나 서랍을 쾅 닫거나 너무 많이 넣어도 안에 든 게 쏟아지지 않습니다.
숨긴 파일은 그 서랍을 열거나, 매트를 들추거나 옮기거나, 휴대폰을 뒤집거나, 펜꽂이나 쓰레기통을 넘어뜨리거나,
입력을 바꾸거나, 메뉴·항목 찾기…·책상에서 보기·모든 파일 꺼내기를 쓸 때만 다시 보입니다.

## 조작법

| 동작 | 하는 일 |
|---|---|
| **클릭** | 파일을 선택합니다(⌘-클릭으로 추가·해제, 빈 화면을 끌어 여러 개 선택, ⌘A로 페이지 전체 선택). 스위치와 버튼도 클릭으로 누릅니다: 전원 버튼, INPUT, 스탠드, 방 조명 스위치, 서랍 손잡이, 휴대폰. |
| **더블클릭** | 파일을 엽니다. 책상 앞쪽 가장자리를 더블클릭하면 **책상을 두드립니다**. 물건이 흔들릴 뿐 파일은 제자리에 있습니다. 매트 가장자리는 펴고, 접힌 자락은 다시 펴고, 빗자루는 제자리로 보냅니다. |
| **끌기** | 파일을 모니터, 숨기는 곳, 책상, 바닥으로 옮깁니다(여러 개를 골랐으면 한꺼번에). 들고 있는 파일을 닫힌 서랍 위에 잠시 올려 두면 서랍이 열립니다. 빗자루, 의자(굴러갑니다), 펜꽂이, 서랍 손잡이, 시계 분침(다른 시간대를 미리 봅니다)도 끌 수 있습니다. |
| **휙 던지기** | 파일을 빠르게 움직이다 놓으면 날아갑니다. 책상 모서리 너머 바닥으로, 또는 쓰레기통 속으로(SWISH!). 펜이 셋 이상 든 펜꽂이를 빠르게 휙 밀면 넘어집니다. |
| **매트 끌기** | 매트 전체가 (위에 놓인 키보드와 함께) 따라옵니다. 빠르게 끌면 주름이 남습니다. |
| **들추기** | 매트의 가장자리나 모서리를 안쪽으로 끌면 들리면서 밑에 있던 더미가 일어섭니다. 놓기 전에 잠깐 멈춰 있으면 잠시 들린 채로 있고, 가운데를 넘겨 놓으면 접힌 채로 남습니다. |
| **당기기** | 매트 모서리를 바깥쪽으로 당기면 주름이 펴집니다(가장자리 더블클릭이나 ‘책상 매트 펴기’도 됩니다). |
| **⌥ (Option)** | 매트 위에서 누르면 손잡이가 나타납니다. ⌥-모서리 끌기로 크기와 방향을 바꾸고(⇧를 누르면 15°씩), ⌥-가운데 끌기로 주름 없이 밀어 옮깁니다. |
| **두 손가락 스크롤** | 책상 위에서 옆으로: **스크롤 빗자루**가 더미를 매트 밑으로 쓸어 넣습니다. 화면 위에서: 페이지를 넘깁니다. 닫힌 서랍 위에서: 안을 살짝 봅니다. |
| **오른쪽 클릭** | 모든 것에 메뉴가 있습니다. 파일(열기, 훑어보기, Finder에서 보기, 복사, **옮기기 ▸** 숨기는 곳 어디로든, 휴지통으로 이동), 모니터, 각 수납함, 매트(밑 들춰 보기, 펴기, 돌리기, 크기, 매트 밑 항목 보기 ▸), 드라이브. 빈 벽을 오른쪽 클릭하면 메뉴 막대 아이콘과 같은 메뉴가 나옵니다. |
| **키보드** (책상을 클릭한 뒤) | Space: 훑어보기 · ⌘O / ⌘↓: 열기 · 화살표: 선택 이동 · ⌘A · ⌘C: 복사 · ⌘F: 항목 찾기… · ⌘Z / ⌘⇧Z: 실행 취소·복귀 · Esc: 옮기던 파일 되돌리기, 엿보기 끝내기. 지우기 키는 없습니다. |

<img src="docs/media/mat-peel.png" width="576" alt="매트 주변: 앞쪽 가장자리를 고무 면이 보이게 들추자 그 밑에 있던 파일 세 개짜리 더미가 서 있는 모습">

Deskterior는 Dock 아이콘이 없습니다. 메뉴는 메뉴 막대의 작은 픽셀 아이콘이나 빈 벽의 오른쪽 클릭 메뉴에 있습니다
(메뉴 막대 항목을 숨겨 두었을 때 편합니다).

## 파일은 안전합니다

- **숨기기는 배치만 바꿉니다.** 서랍 속, 매트 밑, 쓰레기통 속 파일도 바탕화면 폴더에 그대로, 손대지 않은 채 있습니다.
  Finder나 Spotlight, 다른 앱에서도 전과 똑같이 보입니다. Deskterior는 어디에 두었는지만 기억합니다.
- **파일은 직접 요청할 때만 바뀝니다.** 다음 동작뿐입니다.
  - 파일 오른쪽 클릭 메뉴의 **휴지통으로 이동**(단축키 없음)
  - **쓰레기통 비우기…**(이름 목록을 보여 주고 확인을 받은 뒤)
  - Finder에서 파일을 책상에 끌어다 놓기(바탕화면 폴더로 옮겨지고, 다른 디스크에서 왔거나 ⌥를 누르고 있으면 복사)
  - 파일을 다른 앱으로 끌어내기(그 앱이 Finder에서 끌어 온 것과 똑같이 처리)
  - 드라이브 메뉴의 **추출**
  - 설정 ▸ ‘남은 복사본’의 **휴지통으로 이동**(복사가 중간에 끊겼을 때만 나타납니다. 아래 참고)
- **휴지통으로 옮길 뿐 지우지 않습니다.** Deskterior는 파일을 macOS 휴지통으로만 옮기고 절대 지우지 않습니다. 같은
  이름이 있으면 덮어쓰지 않고 " 2", " 3"…을 붙입니다.
- **잠긴 파일은 그대로 둡니다.** 잠긴 파일을 책상에 끌어다 놓으면 바탕화면 폴더로 옮기지 않습니다(⌥를 누르고 있으면
  대신 복사합니다). 복사 도중 앱을 종료하는 등으로 복사가 끊기면 숨은 `.deskterior-partial-…` 폴더가 바탕화면 폴더에
  남습니다. Deskterior는 한 번 알려 주고 설정 ▸ ‘남은 복사본’에 보여 주지만(Finder에서 보기, 휴지통으로 이동) 스스로
  지우지는 않습니다.
- **실행 취소.** ⌘Z는 배치 변경과 Deskterior가 직접 한 파일 작업(휴지통으로 이동, 쓰레기통 비우기…, 책상에 끌어다
  놓기)을 되돌립니다. 휴지통에 넣은 파일은 책상의 원래 자리로 돌아오고, 끌어다 놓은 파일은 원래 있던 곳으로
  돌아갑니다(복사본은 휴지통으로). 추출과 다른 앱으로 끌어내기는 되돌릴 수 없습니다. macOS가 휴지통 접근을 막으면
  그렇다고 알려 주니, Finder의 ‘되돌려 놓기’를 쓰면 됩니다.
- **Finder는 건드리지 않습니다.** 책상은 Finder 바탕화면 아이콘 바로 위에 뜬 창이라 아이콘을 덮을 뿐, Finder 설정을
  바꿔서 숨기지 않습니다(Finder 설정은 읽기만 합니다). Deskterior를 종료하거나 ‘책상 일시 정지’를 하면 원래
  바탕화면이 그대로 돌아옵니다.
- **개인 정보.** 네트워크를 전혀 쓰지 않고, 분석이나 원격 수집도 없습니다. 필요한 권한은 바탕화면 폴더 하나뿐이고
  (다운로드·문서 폴더나 다른 드라이브에서 파일을 끌어다 놓을 때 macOS가 한 번 더 물을 수는 있습니다), 손쉬운 사용·화면
  기록·입력 모니터링 권한은 필요 없습니다. 모든 파일 작업은 상태 폴더의 `operations.log`에 남습니다.

## 설치

Deskterior는 무료라서 Apple 공증(notarization)을 받지 않았습니다(유료 개발자 계정이 필요합니다). 배포판은 ad-hoc
서명이라, 새 버전을 내려받을 때마다 첫 실행을 macOS가 한 번 막습니다. 정상입니다.

1. [최신 릴리스](../../releases/latest)에서 **Deskterior-*버전*.zip**을 내려받아 더블클릭해 압축을 풉니다.
2. **먼저 `Deskterior.app`을 응용 프로그램 폴더로 옮기세요.** 다운로드 폴더에서 바로 열면 macOS가 숨겨진 읽기 전용
   사본으로 실행해서(App Translocation) 권한을 잊어버릴 수 있습니다. 그럴 땐 Deskterior가 알아채고 옮겨 달라고 합니다.
3. Deskterior를 엽니다.
   - **macOS 15 Sequoia 이상:** 열 수 없다는 안내가 나오면 **완료**를 누릅니다(휴지통으로 이동 말고요). **시스템
     설정 ▸ 개인정보 보호 및 보안**을 열어 **보안** 항목까지 내려간 뒤, Deskterior 안내 옆의 **그래도 열기**를 누릅니다
     (약 1시간 동안만 보입니다). 이어서 **그래도 열기**와 암호나 Touch ID로 확인합니다. Control-클릭 ▸ 열기로는
     더 이상 건너뛸 수 없습니다.
   - **macOS 14 Sonoma:** 앱을 Control-클릭(또는 오른쪽 클릭)해서 **열기**를 고르고, 한 번 더 **열기**를 누릅니다.
     개인정보 보호 및 보안의 ‘그래도 열기’ 버튼도 됩니다.
4. 업데이트할 때마다 다시 해 주세요. ad-hoc 서명이라 업데이트 뒤에 바탕화면 폴더 접근을 다시 물을 수도 있습니다.

내려받은 파일이 맞는지 확인하려면, 같은 릴리스의 `.sha256` 파일과 비교하거나 이 저장소의 릴리스 워크플로가
만들었는지 GitHub CLI로 확인하세요(OWNER는 이 페이지 주소의 계정 이름으로 바꾸세요).

```sh
shasum -a 256 -c Deskterior-0.1.0.zip.sha256
gh attestation verify Deskterior-0.1.0.zip --repo OWNER/deskterior
```

## 처음 실행

1. 환영 창이 책상을 소개하고, 모니터에 **전원 ⏻ 버튼을 눌러 바탕화면 연결**이라고 뜹니다.
2. 모니터의 전원 버튼 ⏻을 누르면 macOS가 바탕화면 폴더의 파일에 접근해도 되는지 묻습니다. **허용**을 누르면
   모니터에 파일이 나타납니다. Deskterior는 ⏻을 누른 다음에야 권한을 묻습니다.
3. **허용 안 함**을 눌렀다면 모니터에 **NO SIGNAL**과 버튼 두 개가 뜹니다. **설정 열기**(시스템 설정 ▸ 개인정보 보호
   및 보안 ▸ 파일 및 폴더에서 Deskterior 아래의 ‘데스크탑 폴더’를 켤 수 있습니다)와 **폴더 선택…**(바탕화면 폴더를 고르면 그걸로
   접근이 허용됩니다)입니다.
4. Finder가 바탕화면에 항목을 보이지 않게 설정되어 있으면, 모니터가 먼저 “**그래도 책상에 보여 줄까요?**”라고
   묻습니다(보이기 / 숨겨 두기).
5. 디스플레이가 여러 대면 환영 창에서 나머지 디스플레이를 어울리는 벽으로 덮을지 묻습니다. 벽에 파일을 놓으면
   모니터로 갑니다.

## 안전 모드

Deskterior가 시작될 때 **⌥ (Option)** 키를 누르고 있으세요. 책상이 뜨기 전에 안전 모드 창이 나타나며, 아직 아무것도
건드리지 않은 상태입니다.

- **평소대로 시작**
- **배치 초기화…**: 모든 파일이 모니터로 돌아갑니다. 지금 배치는 상태 폴더에 백업으로 남고, 파일은 지우지 않습니다.
- **상태 폴더 열기**
- **종료**

책상이 멈춰서 반응하지 않으면 터미널에서 `killall Deskterior`를 실행하세요. 바로 사라지고 원래 바탕화면이 돌아옵니다.
파일은 처음부터 건드리지 않았습니다.

## 제거

1. **로그인 시 실행**을 켰다면 설정에서 끄세요.
2. Deskterior를 종료합니다(메뉴 막대 아이콘 ▸ Deskterior 종료).
3. 원한다면 배치, 아이콘 캐시, 설정, 개인정보 보호 권한도 지웁니다. 이름이 앱의 번들 ID를 따르니 앱을 지우기 전에
   먼저 읽어 두세요. 아래 블록 전체를 한 번에 터미널에 붙여 넣으세요.

   ```sh
   ID="$(defaults read /Applications/Deskterior.app/Contents/Info CFBundleIdentifier)" &&
   case "$ID" in io.github.*.deskterior | io.github.deskterior.dev)
     rm -rf ~/Library/Application\ Support/"$ID" ~/Library/Caches/"$ID"
     defaults delete "$ID"
     tccutil reset All "$ID"
   esac
   ```

   첫 줄에서 오류가 나오면 멈추세요. Deskterior가 /Applications에 없는 것입니다. 이 블록은 배치와 그 백업,
   `operations.log`(Application Support), 아이콘 캐시(Caches), 설정(`defaults`), 바탕화면 폴더 권한(`tccutil`)을
   지우며, 번들 ID가 Deskterior의 것이 아니면 아무것도 하지 않습니다.

4. `Deskterior.app`을 휴지통으로 옮깁니다.

## 소스에서 빌드

macOS 15.6 이상과 Xcode 26용 Command Line Tools(Swift 6.2, `xcode-select --install`)가 필요합니다. Xcode는 필요
없습니다. 빌드한 앱은 macOS 14 이상에서 돌아갑니다. 이 저장소를 클론한 폴더에서:

| 명령 | 하는 일 |
|---|---|
| `make build` | `swift build` |
| `make test` | 테스트 (`scripts/swift-test.sh`) |
| `make lint` | 파일 안전 검사 (`scripts/check-file-safety.sh`) |
| `make app` | 이 Mac의 프로세서용 `build/Deskterior.app`, ad-hoc 서명 (`VERSION=0.1.0`으로 버전 지정) |
| `make universal` | 같은 앱을 Apple 실리콘과 Intel 겸용으로 |
| `make install` | `make app` 후 앱을 /Applications로 복사 |
| `make run` | 새로 만든 견본 파일 임시 폴더로 책상을 창에서 실행 |
| `make gif` | `Demos/hero.json`을 녹화해 `docs/media`를 다시 만듦 (ffmpeg 필요) |

직접 빌드한 앱은 격리 표시가 없어서 Gatekeeper가 막지 않습니다. 번들
ID는 클론의 GitHub 원격 저장소에서 정해지고(`io.github.OWNER.deskterior`, 릴리스와 같음), 원격이 없으면 개발용
ID인 `io.github.deskterior.dev`가 됩니다. 무료 자체 서명 인증서로 서명하면 다시 빌드해도 바탕화면 권한이 유지됩니다.
[docs/SIGNING.md](docs/SIGNING.md)를 보세요.

개발용 실행은 진짜 바탕화면을 절대 건드리지 않습니다. 임시 폴더를 지정해야 하고, 진짜 바탕화면이나 그 안의 폴더는
거부합니다(종료 코드 64). 스크립트 데모는 매번 새로 만든 가짜 바탕화면에서 화면 없이 돌고 PNG를 남깁니다(아래 데모는
`.build/demo-out/10-clear-desk`에). 마지막 두 줄은 `make run`이 하는 일입니다.

```sh
scripts/run-demo.sh 10-clear-desk
FIX="$(mktemp -d)"; scripts/make-fixture-desktop.sh "$FIX/desk"
swift run Deskterior --windowed --desktop-folder "$FIX/desk" --state-dir "$FIX/state"
```

더 보기: [docs/DESIGN.md](docs/DESIGN.md)(설계), [docs/DEMOS.md](docs/DEMOS.md)(데모 스크립트),
[docs/SPIKES.md](docs/SPIKES.md)(플랫폼 확인), [CHANGELOG.md](CHANGELOG.md)(영문).

## 알려진 한계

- **공증을 받지 않았습니다.** 내려받은 버전마다 위의 ‘그래도 열기’ 과정이 필요하고, 업데이트 뒤에 바탕화면 접근을
  다시 물을 수 있습니다(ad-hoc 서명은 빌드할 때마다 바뀝니다).
- **Mac 한 대에서만 시험했습니다**(macOS 26의 MacBook Air M2). macOS 14와 15용으로도 빌드하지만 실제로 돌려 본 적은
  없고, Intel용 부분도 Intel Mac에서 돌려 보지 못했습니다.
- **사람이 직접 확인해야 하는 부분이 남아 있습니다.** 다른 앱이 앞에 있을 때의 클릭과 마우스 올리기, 책상을 클릭한
  뒤의 훑어보기와 ⌘Z, 전체 화면 앱 아래에서의 일시 정지, Finder·Mail·Dock 휴지통으로 끌어내기, 실제 휴지통을 거치는
  실행 취소, 다운로드 폴더에서 끌어다 놓기는 자동 테스트로 확인할 수 없습니다. [docs/SPIKES.md](docs/SPIKES.md)를
  보세요.
- 배경화면을 클릭해 바탕화면을 보는 기능(macOS 14 이상)은 책상 위에서는 동작하지 않습니다. 데스크탑 보기, 책상
  엿보기, 책상 일시 정지를 쓰세요.
- 바탕화면 위젯은 책상보다 위에 있습니다. Deskterior는 위젯이 모니터나 서랍을 가리지 않게 방을 조금 옮겨 봅니다.
- 배율 조정된 디스플레이 모드에서는 픽셀이 약간 흐릿합니다.
- **exFAT** 드라이브에 있는 폴더를 책상으로 쓰면 끌어다 놓기와 그 실행 취소가 되지 않습니다. Deskterior가 모든
  이동에 쓰는 ‘덮어쓰지 않는 이름 바꾸기’를 exFAT가 지원하지 않아서, 거절하고 아무것도 바꾸지 않습니다. FAT32와
  APFS에서는 됩니다.
- Finder의 바탕화면은 여전히 밑에 있습니다. 책상이 덮기 전에 Finder 바탕화면에서 아이콘을 선택해 두었다면 Finder에서
  ⌘⌫를 눌렀을 때 휴지통으로 갈 수 있습니다(Finder의 실행 취소로 되돌릴 수 있습니다).
- v0.1에서는 장면 안의 글자가 한국어 설정에서도 영어로 나옵니다: 툴팁, NO SIGNAL 로고, BONK, SWISH!, TIDY!.
